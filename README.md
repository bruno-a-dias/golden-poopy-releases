# 💩 Golden Poopy

App de paródia para Android que calcula quanto o seu tempo no banheiro custa para você e para sua empresa, a partir do seu salário.
Cronômetro, dashboard, conquistas, um mini jogo (Poopy Jump) e um ranking opcional.

> **Aviso:** é uma brincadeira. Os valores são estimativas e não representam custo trabalhista real.

## Como instalar (Android 7.0 ou superior)

1. No celular, toque em **Baixar o APK** acima e aguarde o download.
2. Abra o arquivo baixado. Se o Android pedir, permita **"instalar apps desconhecidos"** para o navegador ou gerenciador de arquivos que você usou.
3. Se o **Play Protect** avisar que o app não é verificado, toque em **"Instalar mesmo assim"**. O app não está na Play Store; ele é distribuído só por aqui.
4. **Atualizando:** instale o APK novo por cima do antigo. Seus dados são mantidos.

Quer conferir a integridade do arquivo? O **SHA-256** está nas notas de cada versão. No Windows: `certutil -hashfile GoldenPoopy-v1.0.3.apk SHA256`.

## Privacidade

- Seus dados (salário, sessões, conquistas) ficam **no seu aparelho**.
- **Nuvem opcional:** o ranking usa um identificador anônimo; todo mundo aparece como "Anônimo". Um apelido só é público se você entrar com o Google **e** ativar "Aparecer no ranking". O backup na nuvem só existe para quem entra com o Google.
- Você pode apagar seus dados do ranking pelo próprio app.
